# Keyword Map — lucoze.com

The targeting layer for Phase 1+. Each target keyword → the page that should rank for it →
priority. Companion to [`growth-plan.md`](growth-plan.md) §3–4 and
[`execution-plan.md`](execution-plan.md).

**Method:** winnable-first. Head terms are owned by directories + incumbents (KareXpert,
HealthPlix, MocDoc) — we win the edges (local, competitor, specialty, long-tail), build
authority, then climb. Difficulty is *relative to us* (a new domain), not absolute.

**Volumes are directional** — validate against Google Keyword Planner + your real GSC query
data (accumulating now). Intent: **I**nformational / **C**ommercial / **T**ransactional.

---

## Cluster A — Local / regional  ⭐ PRIORITY (Phase 1a)
*Why first: lowest competition (few dedicated local pages exist), highest intent, and it's your East-India wedge. Pattern keyword: "[clinic|hospital] management software [place]".*

| Target keyword | Page | URL | Intent | Difficulty |
|---|---|---|---|---|
| clinic management software west bengal / kolkata | **new** state + city | `/in/locations/west-bengal/`, `/in/locations/kolkata/` | C/T | **Low** |
| hospital management software kolkata | Kolkata page | `/in/locations/kolkata/` | C/T | Low |
| clinic software patna / bihar | new | `/in/locations/bihar/`, `/in/locations/patna/` | C/T | Low |
| hospital software ranchi / jharkhand | new | `/in/locations/jharkhand/` | C/T | Low |
| clinic management software bhubaneswar / odisha | new | `/in/locations/odisha/` | C/T | Low |
| clinic software lucknow / uttar pradesh | new | `/in/locations/uttar-pradesh/` | C/T | Low |
| HMS software guwahati / northeast india | new | `/in/locations/northeast-india/` | C/T | Low |

**Build order:** West Bengal + Kolkata (flagship) → Bihar/Patna → Jharkhand → Odisha → UP → Northeast.
**URL:** clean `/in/locations/[slug]/` (keyword lives in title/H1/content — a keyword-stuffed URL isn't needed and reads spammy at scale).
**Quality gate:** 60%+ unique content per page — real local cities, languages (Bengali/Hindi/Odia), state health-scheme context, local support promise. **Not** swapped-noun doorway pages. Cap at the ~10–12 places above; do not mass-generate.

## Sequencing summary
1. **Now (1a):** local pages — WB + Kolkata flagship, then the other states/cities.
2. **Next (1b):** competitor comparison pages.
3. **Then (C/D):** optimize existing specialty/feature titles.
4. **Phase 2 (E):** compliance content cluster + internal linking + backlinks.
5. **Phase 3+ (F):** head terms once domain authority supports it.

## Measure (per keyword, in GSC)
Impressions appear first (page is being considered) → average position climbs → clicks
follow. Watch **Performance → Queries** filtered to each cluster. A page that gets
impressions but sits at position 15–30 = on the right track, needs more depth/links, not a
rewrite.
